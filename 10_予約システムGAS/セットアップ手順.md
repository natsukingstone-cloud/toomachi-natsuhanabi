# 座席予約システム セットアップ手順（GAS）

Google Apps Script（GAS）はGoogleアカウントに紐づくため、デプロイ（公開）作業はご自身で行っていただく必要があります。以下の手順通りに進めれば10分程度で完了します。

## 1. 予約台帳用のGoogleスプレッドシートを作成

1. Google Drive で新規スプレッドシートを作成（名前は「とおまち夏花火ナイト_予約台帳」など）
2. メニューの「拡張機能」→「Apps Script」を開く

## 2. コードを貼り付け

1. 開いたApps Scriptエディタで、デフォルトの `Code.gs` (または `コード.gs`) の中身を全部削除し、こちらの **`Code.gs`** の内容をそのまま貼り付け
2. 左側の「＋」→「HTML」でファイルを新規作成し、ファイル名を **`index`**（拡張子は付けない）にする
3. 作成した `index.html` の中身を全部削除し、こちらの **`index.html`** の内容を貼り付け
4. 保存（Cmd+S）

## 3. 設定値を確認・変更

`Code.gs` の先頭にある設定値を必要に応じて変更してください。

```javascript
const CAPACITY = 200;                              // 定員（先着予約の上限人数）
const ORGANIZER_EMAIL = 'natsukingstone@gmail.com'; // 運営通知の送信先
const EVENT_DATE_TEXT = '8月中旬の土曜（詳細日程は公式LINEでご案内）';
const SEAT_PRICE = 1500; // 円（税込）／1名
```

## 4. Webアプリとして公開

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択（歯車アイコン）で「ウェブアプリ」を選択
3. 設定：
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」をクリック
5. 初回は権限の承認を求められます（メール送信・スプレッドシート編集の権限）。ご自身のGoogleアカウントで許可してください
6. 発行された **ウェブアプリのURL** をコピー

## 5. LPと連携

コピーしたURLを教えていただければ、LP（`09_LP/index.html`）内の以下のボタンのリンク先をこのURLに差し替えます。

- ヘッダーの「予約」ボタン
- 「席を予約しておく」ボタン（2箇所）
- フッターの「観覧席予約フォームへ（準備中）」ボタン
- 下部固定バーの「席を予約する」ボタン

## 動作の仕組み

- 予約が入るたびに、スプレッドシートの「予約データ」シートに1行追加されます
- 定員200名を超える人数の予約は自動的に受付できないようにブロックされます（同時アクセスにも対応済み）
- メールアドレスを入力した予約者には自動で確認メールが届きます
- 運営者（`ORGANIZER_EMAIL`）にも新規予約のたびに通知メールが届きます

## キャンセルしたい予約が出た場合

現時点では専用のキャンセルフォームは作っていません。スプレッドシートの「予約データ」シートで、該当行の「ステータス」列を `受付` から `キャンセル` に書き換えてください。定員カウントから自動的に除外されます（フォーム側の「残り◯名」表示にもすぐ反映されます）。

予約者向けのセルフキャンセルフォームが必要でしたら、追加で作成できるのでお知らせください。

## テストの仕方

1. デプロイ後のURLに自分でアクセスし、テスト予約を1件送信
2. スプレッドシートに行が追加されているか確認
3. 入力したメールアドレスに確認メールが届くか確認
4. `ORGANIZER_EMAIL` 宛に通知メールが届くか確認
5. 問題なければテスト行は削除してOKです（削除しても定員カウントには影響しません）
